# Storefront (черновик главной страницы)

Первая локальная версия фронтенда: главная страница на Next.js + Tailwind, с тестовыми
(mock) данными вместо реального каталога. Бэкенда и БД здесь пока нет — это чисто
визуальная отладка (см. план проекта: сначала фронтенд, потом бэкенд/БД, потом окружение).

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Что уже есть

- Шапка: логотип, поиск, вход, корзина, навигация по каталогу
- Баннер (hero) с призывом к действию
- Блок доверия (гарантия, доставка, проверка, лояльность)
- Сетка разделов каталога (8 категорий из плана проекта)
- Блок «Популярное и новинки» с карточками товаров
- Подвал с контактами и ссылками

Все товары/категории — тестовые данные в `lib/mock-data.ts`, изображений пока нет
(вместо фото — плейсхолдер-иконка), логотип — текстовый (бренда/цветов ещё нет,
поэтому взята нейтральная схема: тёмно-синий + оранжевый акцент).

## Как сменить фирменный стиль позже

Все цвета вынесены в CSS-переменные в `app/globals.css` (`--brand`, `--accent`, `--ink`,
`--muted`, `--surface`, `--border-color`) — компоненты используют только имена, не
конкретные hex-коды. Чтобы поменять палитру под реальный бренд, достаточно
отредактировать значения в этом одном файле. Название «МобДетали» — временное
(в `components/Header.tsx`, `components/Footer.tsx`, `app/layout.tsx`).

## Дальше по плану

1. Собрать обратную связь по вёрстке главной, при необходимости — поправить.
2. Добавить остальные страницы (каталог категории, карточка товара, корзина).
3. Перейти к бэкенду (NestJS) и базе данных (PostgreSQL) — см. документ архитектуры проекта.
