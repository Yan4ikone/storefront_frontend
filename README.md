# Storefront (черновик витрины)

Локальная версия фронтенда: главная, каталог, карточка товара, корзина и страница
входа/регистрации — на Next.js + Tailwind, с тестовыми (mock) данными вместо реального
каталога. Бэкенда и БД здесь пока нет — это визуальная отладка (см. план проекта:
сначала фронтенд, потом бэкенд/БД, потом окружение).

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Что уже есть

- **Главная** (`/`) — баннер, блок доверия, сетка разделов каталога (клик — всплывающий
  список подпунктов), блок «Популярное и новинки».
- **Каталог** (`/catalog`) — обзор всех разделов; **раздел каталога** (`/catalog/[slug]`)
  — листинг товаров с визуальными фильтрами (совместимость, цена) и сортировкой.
- **Карточка товара** (`/product/[slug]`) — галерея-плейсхолдер, цена, выбор количества,
  «В корзину», характеристики, похожие товары.
- **Корзина** (`/cart`) — реально работает: товары добавляются из карточек и со страницы
  товара, можно менять количество и удалять; данные хранятся в `localStorage` браузера
  (временное решение до бэкенда — см. `lib/cart-context.tsx`). Кнопка «Оформить заказ»
  пока отключена — оформление появится вместе с бэкендом.
- **Вход/регистрация** (`/login`) — визуальная форма, без реальной авторизации (появится
  вместе с модулем Users & Auth бэкенда).
- Шапка и подвал — на всех страницах (вынесены в `app/layout.tsx`), счётчик товаров в
  иконке корзины обновляется в реальном времени.

Все товары/категории — тестовые данные в `lib/mock-data.ts`, изображений пока нет
(вместо фото — плейсхолдер-иконка), логотип — текстовый (бренда/цветов ещё нет,
поэтому взята нейтральная схема: тёмно-синий + оранжевый акцент).

## Как сменить фирменный стиль позже

Все цвета вынесены в CSS-переменные в `app/globals.css` (`--brand`, `--accent`, `--ink`,
`--muted`, `--surface`, `--border-color`) — компоненты используют только имена, не
конкретные hex-коды. Чтобы поменять палитру под реальный бренд, достаточно
отредактировать значения в этом одном файле. Название «МобДетали» — временное
(в `components/Header.tsx`, `components/Footer.tsx`, `app/layout.tsx`).
